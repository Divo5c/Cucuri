=====================================================
FILE: SpaceEdu-Design-Spec.txt | ENCODING: UTF-8 | FORMAT: plain text, deterministic

OUTPUT: One single self-contained file `index.html`. No build step. No frameworks. No external JS.

--------------------------------------------------------------------------------
0. HOW TO READ THIS FILE
--------------------------------------------------------------------------------
- Section numbers are stable. Implement in order 1..13.
- `calc(N * var(--u))` means literal CSS `calc(<N> * var(--u))`. Never substitute px.
- "EXACT" means byte-for-byte copy unless noted.
- All lengths for hero MUST use var(--u). New sections also use var(--u).
- Source order matters for responsive tiers (Sec.8) and animations.

--------------------------------------------------------------------------------
1. CONCEPT
--------------------------------------------------------------------------------
Site: "SpaceEdu". Space-themed education marketing site.
Viewport 1 = cinematic full-viewport hero:
- Looping silent video of ONE planet fills viewport (background).
- Centered over it: eyebrow "PLANET", huge serif planet name, short cyan rule,
  paragraph (lede), glossy white pill button "GET STARTED".
- Flanking button, cropped by left/right screen edges: two transparent planet
  cut-outs (2048px PNG w/ alpha) with serif labels.
- Planets: EARTH, VENUS, MARS. Exactly one "featured" (background clip + headline).
  Other two fill LEFT and RIGHT slots. Clicking side planet features it; slots
  refill with other two. Earth featured on load. Fully reversible:
  earth->[venus,mars], venus->[earth,mars], mars->[earth,venus], back to start.
Below hero (same file, scrollable page):
- #planets: 3 cards (EARTH/VENUS/MARS) with still image, copy, [Feature X] + [Join].
- #tuition (keep nav spelling "Tution"): 3 pricing cards Flyby $19 / Orbit $49 / Mission $99.
- #tutorials: 4 numbered lessons (01..04).
- #blog: 3 posts with dates.
- #enroll: two-column box: copy + form (name,email,track) + note; footer with logo/links/copyright.
Scroll button in hero scrolls to #planets. Card [Feature X] calls hero show(X) then scrolls to top.

2. TECH CONSTRAINTS
--------------------------------------------------------------------------------
- DOCTYPE html, <html lang="en">, charset UTF-8, viewport width=device-width,initial-scale=1.
- <head> contains: meta description, theme-color #04101f, OG tags, favicon (Sec.3),

  ONE <style> block with ALL CSS.
- <body> contains: .stage hero + <main class="sections"> + ONE <script> before </body> with ALL JS.
- No external JS files. Only external URLs: Google Fonts CSS + CloudFront assets.
- html{scroll-behavior:smooth} + @media (prefers-reduced-motion:reduce){html{scroll-behavior:auto}}.
